Air sensor (BME680)

The BME680 warms itself, so it reads a little hot and its humidity a little low. Put a reference thermometer next to the bin for a few minutes, type its reading, press SET OFFSET, then SAVE SETTINGS. Humidity and pressure offsets are optional. The gas reading has no manual offset: it learns its own baseline in normal air, and RESET GAS BASELINE restarts that.

Not paired

Hand the Wi-Fi name and password to a bin over Bluetooth, read back the address it gets, then switch its Bluetooth off so only Wi-Fi stays on. Pairing asks for the 6-digit code the bin shows on its touchscreen: it keeps strangers out and encrypts the link, so the Wi-Fi password cannot be overheard.

Not tested

The bins copy their readings to Firebase so the phone app keeps working away from this Wi-Fi. Local Wi-Fi always comes first: this dashboard and the app both use the bins’ own API whenever a bin answers, and the app falls back to Firebase only when none does.

312 MB of the 10 GB the free Firebase plan allows each month. Each bin writes every 5 s while a phone is watching over cloud, every minute otherwise, and at once when an alert starts. Commands the app sends through the cloud (LOCK, UNLOCK, COLLECT) reach the bin within a few seconds.

Operator access

The dashboard always opens as a collector, the same as the phone app. Operator needs the PIN, and drops back to collector after 2 min with this tab hidden. After 5 wrong PINs it waits 30 s, longer each time. Only an operator can change the PIN, and only by typing the current one first.

Simulation

AUTO reads the real hardware and lets the firmware drive the outputs. MANUAL holds the value you set, one row at a time.
