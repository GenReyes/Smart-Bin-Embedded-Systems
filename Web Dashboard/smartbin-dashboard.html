Air sensor (BME680)

-- / -- °C
--

The BME680 warms itself, so it reads a little hot and its humidity a little low. Put a reference thermometer next to the bin for a few minutes, type its reading, press SET OFFSET, then SAVE SETTINGS. Humidity and pressure offsets are optional. The gas reading has no manual offset: it learns its own baseline in normal air, and RESET GAS BASELINE restarts that.

Tilt sensor (BMI160)

--
--

The bin counts as tilted when it leans more than the tilt threshold away from the saved upright angle. Stand the bin straight and press USE NOW, or type the pitch and roll, then SAVE SETTINGS. With the power-up switch on, the angle the bin stands at when it is switched on becomes upright, so it never starts in tamper. Switch it off to keep the saved angle across restarts. Starting calibration mode also saves the angle the bin stands at now.

Lid and lock

After the lid closes it stays shut for the closed time even if someone is still in front of it, so it does not flap open and shut. 0 lets it open again at once.

Touchscreen

--

If presses land in the wrong place, press CALIBRATE TOUCH. The bin shows four crosses one after another: press each one firmly, then let go. The result is saved on the bin straight away. It can also be started on the bin itself by holding a finger anywhere on the screen for 5 seconds. Needs the bin’s Wi-Fi.

Values are read-only until calibration mode is on. Saving sends them to the bin and they survive a restart.

Not paired

Gives a bin a new Wi-Fi name and password over Bluetooth. The bin keeps its current Wi-Fi until the new one works, and your laptop can stay on Wi-Fi too.

  1. On the bin: tap i (top left), then WI-FI SETUP, and type the Collect PIN (the same 4 digits as for COLLECT).
  2. Here: press PAIR A BIN and pick SmartBin-01 (or 02) in the list the browser shows.
  3. The bin shows a 6-digit pairing code. Windows or your phone opens its own pairing window: type the code there, not on this page.
  4. Pick the network, type its password, press SEND WI-FI. The bin shows its new IP address, and so does this page.
  5. Press TURN BT OFF when you are done.

Not tested

The bins copy their readings to Firebase so the phone app keeps working away from this Wi-Fi. Local Wi-Fi always comes first: this dashboard and the app both use the bins’ own API whenever a bin answers, and the app falls back to Firebase only when none does.

Each bin writes every 5 s while a phone or this dashboard is watching over the cloud, every minute otherwise, and at once when an alert starts. LOCK, UNLOCK and COLLECT sent through the cloud reach the bin within a few seconds. The data meter appears once the bins report it.

Operator access

The dashboard opens on the start page every time, the same as the phone app. Operator needs the PIN, and drops back to collector after 2 min with this tab hidden. After 5 wrong PINs it waits 30 s, longer each time. Only an operator can change the PIN, and only by typing the current one first.
